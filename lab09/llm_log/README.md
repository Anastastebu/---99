# Журнал протоколу LLM-експерт

Дата експерименту — 18.11.2026. Модель — ChatGPT, сімейство GPT‑6. Точний ідентифікатор збірки, temperature і seed у чаті недоступні. Генератор CSV детермінований, тому seed для даних не потрібен.

| Крок | Вхід | Вихід | Рішення, яке студентка перевіряє перед здачею |
|---|---|---|---|
| Схема й проєкт | «допоможи виконати лабораторну роботу виконай всі вимоги та оясни як я це маю зробити», ЛР09, звіт ЛР07 | Схема, підготовка даних, еталонні запити, програма перевірки | Звірити класи та предикати з власними файлами ЛР 6–8. Підтвердити допустимість демонстраційного набору. |
| Контрольний Text-to-Cypher | Prompt v1 у prompt_v1.txt і десять CQ | raw_t2c.jsonl | Переглянути 3 контрольні помилки, звірити правильні результати з еталоном. |

Сирі Cypher-кандидати створені ChatGPT у межах підготовки цієї лабораторної та збережені для відтворення. У трьох кандидатах навмисно закладені контрольні помилки. Результат демонструє роботу перевірки на фіксованому наборі. Він не вимірює якість незалежної генерації моделі. Для власної незалежної оцінки запустіть prompt v1 в окремому чаті або через свій API, збережіть всі сирі відповіді в новому JSONL і виконайте `.\.venv\Scripts\python.exe run_lab.py --candidates tests/my_t2c.jsonl`. У журнал внесіть фактично доступні назву моделі, версію, параметри і власні рішення. Перед здачею додайте експорт чату для повного журналу взаємодії. Паролі та ключі в журнал не додавайте.
